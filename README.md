### 四旋翼无人机 × 车模：空地协同控制

第 21 届全国大学生智能汽车竞赛 **“飞跃雷区”组全国总决赛冠军**。项目由四旋翼无人机、图像板、飞控和车模组成：无人机识别地面信标与车灯，将视觉、姿态和高度信息交给飞控；飞控完成相机模型、三摄融合和路径规划，再通过通信控制车模执行。
